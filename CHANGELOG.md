## [1.0.0] - 2026-10-03

First release.

### Added

- Launch any number of applications after you sign in to Windows, each after its own delay.
- Application picker that finds installed programs automatically (Start menu, Microsoft Store
  apps and registered programs) with instant search, plus **Browse for EXE** for portable programs.
- Reorder, enable/disable, edit and remove applications; **Launch Now** for a quick test.
- Delays counted from sign-in, or one application after another.
- Optional wait for a network connection, and skipping of applications that are already running.
- WinStart starts with Windows and waits in the notification area (system tray).
- Startup history showing what was launched, when, and whether it worked.
- Built-in updates from GitHub Releases: automatic or manual checks, release notes, and a
  one-click **Download and Install** that verifies the download's SHA-256 checksum.
- Per-user installer that needs no administrator rights and keeps your settings when upgrading.
